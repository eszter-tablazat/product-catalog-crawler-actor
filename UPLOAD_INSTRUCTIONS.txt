APIFY PRODUCT CRAWLER v1.2.12 - GITHUB FELTOLTES

1. Bontsd ki az apify-product-crawler-v1.2.12-github-upload.zip fajlt.
2. A kibontott mappa fajljait toltsd fel a GitHub repo GYOKEREBE.
3. A GitHubon engedelyezd a meglevo fajlok felulirasat/cserejet.
4. Commit uzenet: Release v1.2.12 - Apify proxy support
5. Apify Console -> Actor -> Builds -> Start build.
6. A sikeres build kapja a latest cimket, majd indits tesztfutast.

AZ UJ LOGBAN EZEKNEK KELL LATSZANIA:
- product-catalog-crawler-actor@1.2.12
- Crawler throttle settings
- Crawler proxy enabled

PROXY MODOK:
- auto: alapertelmezett, Apify Proxy. Eloszor ezzel tesztelj.
- residential: fizetos lakossagi proxy erosen vedett oldalakhoz.
- none: proxy nelkul; 429-et ado oldalakhoz nem ajanlott.

HA AZ INOXMONT.HU AUTO MODBAN IS 429-ET AD:
1. Apify Console -> Actor -> Settings -> Environment variables.
2. Uj valtozo: PROXY_MODE = residential
3. Uj valtozo: PROXY_COUNTRY = HU
4. Mentsd el, majd indits uj futast.

FONTOS: a residential proxy adatforgalma fizetos az Apify dijazasa szerint.
